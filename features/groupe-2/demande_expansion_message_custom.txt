Proposition technique

Peut-être à l'upload du message stocker une version "clean" dans le champ classique de l'objet message, puis dans les metadata ou un autre champ stocker une version html custom. Donc en ajoutant dans l'endpoint POST /message un champ dans le body du type custom-text: qui accepterait du html.
